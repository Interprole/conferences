# Конференции по лингвистике

Статический каталог для GitHub Pages. Без сборки и внешних библиотек.

Карточки и таблица, поиск, фильтры по срокам и источникам, выделение теоретической лингвистики, история продлений, архив, локальное избранное, CSV и календарь ICS.

## Публикация

Владелец включает Pages самостоятельно: **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Файлы уже расположены в корне; сборка не нужна.

## Данные

- `data/linguistlist.json`: публичные объявления LINGUIST List и записи доступного каталога.
- `data/mosling.json`: сведения о конференциях из рассылки Мослинг. Только структурированные данные; исходные письма, заголовки доставки, персональные контакты и закрытые ссылки на встречи не публикуются.
- `data/overrides.json`: проверенные уточнения полей по стабильному `id`. Имеют приоритет над автоматическим сбором.
- `data/linguistlist-status.json` и `data/mosling-status.json`: независимые журналы проверок и ошибок.
- `data/status.json`: общие сведения о расписании.

Начальная загрузка неполная. Прочитаны 116 найденных писем за 2026 год, из них объединены 47 конференций. При первом обходе LINGUIST List удалось получить 31 из 59 страниц каталога и часть подробных объявлений; это не означает постоянную недоступность остальных страниц. Карточки из списков явно помечены как разобранные частично. Вложения и некоторые дополнительные поля пока не проверены. Архив до 2026 года не импортировался целиком.

`null` означает неизвестное значение. Отсутствие сведений о сборе или ограничении **не** означает бесплатное участие или отсутствие ограничений. `subject_languages` — исследуемые языки, `working_languages` — языки тезисов и выступлений: эти поля не взаимозаменяемы. При конфликтующих датах используется `date_conflict`, а не предположение.

Теоретические конференции выделяются по названию и рубрикам: синтаксис, семантика, морфология, фонетика, фонология, просодия, типология и теория грамматики. Смешанные конференции отмечаются отдельно. Специализированные NLP, нейролингвистика, переводоведение и культурология исключаются.

## Обновления

Публичный сборщик запускается GitHub Actions ежедневно в **06:00 UTC / 09:00 МСК** и вручную через **Actions → Refresh conference catalogue → Run workflow**. GitHub может запускать cron с задержкой. Если Actions остановлен или отключён, ежедневные проверки не выполняются; текущий статус виден в журнале.

Сборщик сначала собирает ссылки со всех страниц текущего каталога и последних объявлений, затем разбирает посты. Официальные RSS Calls и Conferences дополняют поиск новых объявлений; журнальные выпуски в RSS исключаются. Посты будущих конференций проверяются повторно каждый день.

Очередь `data/linguistlist-crawl.json` хранит прогресс по каждому URL: результат, последнюю попытку, ошибки, время следующей попытки. После каждой страницы сохраняются данные и очередь. Следующий запуск продолжает незавершённый обход; полная новая итерация начинается после завершения предыдущей, не чаще раза в день. Параллельно ежедневно проверяются свежая лента и уже известные будущие конференции.

Запросы последовательные, с интервалом от 2 секунд. Тайм-ауты и ответы 5xx/429 повторяются до 3 раз с увеличением паузы и учётом `Retry-After`. При 403 сборщик прекращает запросы; после исчерпания попыток при 429 сохраняет очередь и выдерживает паузу для всего сайта. Ошибка отдельного поста не останавливает остальные посты. Лимит времени по умолчанию — 45 минут; лимиты попыток — 100 страниц/лент и 500 постов за запуск.

Журнал отдельно показывает успешные загрузки за запуск, покрытие текущего обхода, остаток очереди, записи без подробного объявления и записи, требующие ручной проверки. `complete` относится только к обходу текущего каталога и свежих объявлений. `details_complete: false` означает, что все свободно изложенные условия и официальные сайты ещё не проверены. Исторический архив LINGUIST List целиком в эту оценку не входит.

Сбой загрузки не удаляет конференции и не затирает известные поля пустыми значениями. Старое объявление не может отменить более новый срок. Официальные сайты и сложные условия дополнительно проверяются в ежедневной задаче.

Для Мослинг используется отдельная ежедневная задача ChatGPT в **09:00 Europe/Moscow**, которая читает рассылку через подключённую почту и обновляет данные через GitHub. Доступ к Gmail не передаётся в публичный репозиторий или Actions. При недоступности подключения задача должна сообщить об ошибке и сохранить предыдущие данные. Задача также дополняет недостающие конференции и уточняет продления по LINGUIST List и сайтам организаторов.

Сроки на экране пересчитываются при открытии и каждую минуту. Если точное время не известно, отображается календарная разница дат по Москве, а часовой пояс не придумывается. Прошедшие конференции и закрытые сроки остаются в каталоге.

## Локальная проверка

```sh
npm run check
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Для обновления публичных источников:

```sh
python scripts/refresh.py
```

Используются стандартные библиотеки Python и Node.js. Тесты проверяют границы дат и часовых поясов, сохранение архива, историю продлений, объединение источников, безопасность CSV и экспорт календаря.
