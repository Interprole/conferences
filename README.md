# Конференции по лингвистике

Статический каталог для GitHub Pages. Без сборки и внешних библиотек.

Таблица с группами воркшопов, светлая / тёмная / системная тема, поиск, фильтры по срокам и источникам, выделение теоретической лингвистики, история продлений, архив, локальное избранное, CSV и календарь ICS.

## Публикация

Владелец включает Pages самостоятельно: **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Файлы уже расположены в корне; сборка не нужна.

## Данные

- `data/linguistlist.json`: публичные объявления LINGUIST List и записи доступного каталога.
- `data/mosling.json`: сведения о конференциях из рассылки Мослинг. Только структурированные данные; исходные письма, заголовки доставки, персональные контакты и закрытые ссылки на встречи не публикуются.
- `data/overrides.json`: проверенные уточнения полей по стабильному `id`. Имеют приоритет над автоматическим сбором.
- `data/linguistlist-status.json` и `data/mosling-status.json`: независимые журналы проверок и ошибок.
- `data/status.json`: общие сведения о расписании.

Начальная загрузка неполная. Прочитаны 116 найденных писем за 2026 год, из них объединены 47 конференций. При первом обходе LINGUIST List удалось получить 31 из 59 страниц каталога и часть подробных объявлений; это не означает постоянную недоступность остальных страниц. Карточки из списков явно помечены как разобранные частично. Вложения и некоторые дополнительные поля пока не проверены. Архив до 2026 года не импортировался целиком.

`null` означает неизвестное значение. Отсутствие сведений о сборе или ограничении **не** означает бесплатное участие или отсутствие ограничений. `subject_languages` — исследуемые языки, `working_languages` — языки тезисов и выступлений: эти поля не взаимозаменяемы. При конфликтующих датах используется `date_conflict`, а не предположение.

Теоретические конференции выделяются по названию и рубрикам: синтаксис, семантика, морфология, фонетика, фонология, просодия, типология и теория грамматики. Смешанные конференции отмечаются отдельно. Специализированные NLP, нейролингвистика, переводоведение и культурология исключаются.

## Обновления

Ежедневная задача в **09:00 Europe/Moscow** читает LINGUIST List, официальные сайты и Мослинг через подключённые GitHub и Gmail. Объявления анализируются по содержанию: тема, исследуемые языки и связь секций с основной конференцией проверяются самостоятельно. Автоматический парсинг по расписанию отключён. Доступ к Gmail не передаётся в публичный репозиторий или Actions. При недоступности источника задача сохраняет предыдущие сведения и записывает ограничение проверки.

`data/editorial.json` хранит русские подписи мест, рубрик и исследуемых языков, содержательные резюме и явные списки стабильных ID для групп конференций. Связи не выводятся автоматически из названий, места или дат. Редакторская работа над отображением не меняет время последней проверки источника. Уточнение содержания и проверка всех условий — разные операции: основание каждого резюме записано отдельно. Секции сохраняют отдельные сроки, правила, ссылки и историю. Группа занимает одну позицию при разбивке списка на страницы; поиск и фильтры действуют на её отдельные записи.

Старые файлы и очередь сборщика сохранены для истории. Диагностический сборщик `scripts/refresh.py` и workflow **Refresh conference catalogue** доступны только для явного ручного запуска. Ежедневная задача их не запускает и не использует автоматическую классификацию вместо чтения объявлений. Статус прежнего обхода не означает полноту ручной проверки.

Сроки на экране пересчитываются при открытии и каждую минуту. Если точное время не известно, отображается календарная разница дат по Москве. Прошедшие конференции и закрытые сроки остаются в каталоге.

Тема по умолчанию следует настройке системы, в том числе при её изменении. Ручной выбор «Светлая» или «Тёмная» сохраняется только в текущем браузере. Выбор «Системная» снова включает следование системе.

## Локальная проверка

```sh
npm run check
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Для явно запрошенного диагностического запуска старого сборщика:

```sh
python scripts/refresh.py
```

Используются стандартные библиотеки Python и Node.js. Тесты проверяют границы дат и часовых поясов, сохранение архива, историю продлений, объединение источников, безопасность CSV и экспорт календаря.
